# Sales God Mode — Cloud APK Build

1. Create a GitHub repository.
2. Upload this project and push to `main`.
3. Open **Actions**.
4. Select **Build Sales God Mode APK**.
5. Click **Run workflow** if needed.
6. Wait for the green check.
7. Open the workflow run.
8. Download **Sales-God-Mode-debug-APK** from Artifacts.
9. Extract it and install `app-debug.apk` on Android.

This is a debug/test APK. A production release later needs a private signing key.
No domain or hosting is required for the app's offline core.
